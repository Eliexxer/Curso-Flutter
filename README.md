## 📂 Estructura del Repositorio

### 🎯 1. Conceptos Fundamentales de Dart (`dart_basics/`)
Ejercicios de sintaxis y bases del lenguaje Dart antes de entrar a Flutter:
- **Tipos de datos y Variables:** `final`, `const`, `late`, listas, sets y mapas.
- **Funciones y Parámetros:** Parámetros opcionales, posicionales, nombrados y funciones flecha.
- **Programación Orientada a Objetos (POO):**
  - Clases y constructores nombrados (`name constructors`).
  - Getters, Setters y Aserciones (`assert`).
  - Clases abstractas y enumeraciones (`enum`).
  - **Mixins:** Composición y reutilización de código entre jerarquías de clases.
- **Programación Asíncrona:**
  - `Future`, `async` y `await`.
  - Manejo de errores con `try / catch / on / finally`.
  - `Streams` y manejo de eventos continuos.
